# Blue-Green Deployment Task Manager

A simple DevOps mini project demonstrating:

- Docker containerization
- Jenkins CI/CD pipeline
- Blue-Green deployment strategy
- Terraform infrastructure provisioning
- Monitoring using Prometheus and Grafana

---

# Tech Stack

- React
- Node.js
- Express
- Docker
- Jenkins
- Terraform
- AWS
- Prometheus
- Grafana

---

# Project Structure

```text
backend/
frontend/
docker-compose.yml
```

---

# Features

- Add Tasks
- Delete Tasks
- Mark Tasks Completed
- Dockerized Full Stack Application
- CI/CD Ready
- Cloud Deployment Ready

---

# Run Project Locally

## Start Containers

```bash
docker-compose up --build
```

# Access Application

Frontend:

```text
http://localhost:3000
```

Backend:

```text
http://localhost:5000/tasks
```
